نظام الخدمة الوطنية - الجداول والخدمات
=====================================

التشغيل:
- انقر مرتين على run.bat أو على اختصار NationalService في سطح المكتب.
- يعمل بدون إنترنت. البيانات تُحفظ في: service_national\data\service_national.db (بجانب البرنامج).

الميزات:
1. الأفواج: مجموعتان (أ، ب) × 5 أفواج = 10. إنشاء تلقائي.
2. الطلاب: بيانات كاملة (الاسم، اسم الأب، الرقم الوطني، تاريخ الميلاد، الهاتف، العنوان، فصيلة الدم، الرتبة، تاريخ الالتحاق، ملاحظات).
3. توليد جدول أسبوعي تلقائي:
   - حراسة، مطعم، مطبخ، تنظيف، مرحاض (فوج + عدد يومي).
   - الفوج في الحراسة لا يعمل مطعم/مطبخ ذلك اليوم.
   - توزيع عادل (round-robin).
4. خدمات اختيارية (اسم، عدد، مستلم، فوج) مع توقيع.
5. طباعة PDF احترافية (عربي RTL) مع مساحة توقيع وتاريخ/يوم.
   - كل قائمة منفصلة: حراسة / مطعم / مطبخ / تنظيف / مرحاض / اختيارية / طلاب.
6. تعديل التعيينات يدوياً.
7. إعدادات: اسم الوحدة، عدد افتراضي للمرحاض/الحراسة.

ملاحظات:
- الطباعة: "توليد PDF" يفتح الملف للمعاينة؛ "طباعة مباشرة" يرسل إلى الطابعة الافتراضية.
- لنسخ احتياطي: انسخ مجلد data\.
